# Modules & Routing

WyFlask introduces the `Module` abstraction and `Registry` manager over standard Flask Blueprints, simplifying route grouping, prefixing, and application-level registration.

---

## What is a Module?

A `Module` is a high-level wrapper around Flask's `Blueprint`. It groups related routes, views, models, and services into a self-contained unit.

```python
from wyflask.routing import Module

# Initialize module with a url_prefix
users_module = Module("users", url_prefix="/users")

@users_module.route("/")
def list_users():
    return {"users": ["Alice", "Bob"]}

@users_module.route("/<int:user_id>")
def get_user(user_id: int):
    return {"user_id": user_id}
```

---

## Module Directory Structure

A standard module generated by `wyflask module create <name>` follows this structure:

```text
app/modules/<module_name>/
├── __init__.py      # Instantiates Module and imports routes
├── routes.py        # Route handlers and HTTP endpoints
├── services.py      # Business logic orchestration
├── repositories.py  # Data persistence operations
├── models.py        # Domain entities or ORM models
└── schemas.py       # Input validation & serialization
```

### Module `__init__.py` Pattern
```python
from wyflask.routing import Module

users_module = Module("users", url_prefix="/users")

# Ensure routes are loaded so decorators execute
from . import routes
```

### Module `routes.py` Pattern
```python
from flask import request
from wyflask.responses import success, error
from wyflask.exceptions import NotFoundError
from . import users_module
from .services import UserService

user_service = UserService()

@users_module.route("/", methods=["GET"])
def get_all():
    users = user_service.get_all_users()
    return success("Users fetched successfully", data=users)

@users_module.route("/<int:user_id>", methods=["GET"])
def get_one(user_id: int):
    user = user_service.get_user_by_id(user_id)
    if not user:
        raise NotFoundError(f"User with ID {user_id} not found")
    return success("User retrieved", data=user)
```

## Registering Modules with `Registry`

WyFlask uses a singleton `registry` in `wyflask.routing` to collect and mount modules onto the Flask application during startup in `create_app()`.

In your `run.py`:

```python
from wyflask import create_app
from wyflask.routing import registry

# Import all module instances
from app.modules.main import main_module
from app.modules.users import users_module
from app.modules.auth import auth_module

# Register with WyFlask registry
registry.register(main_module)
registry.register(users_module)
registry.register(auth_module)

# create_app() automatically binds all registered blueprints to the Flask instance
app = create_app("app.config.AppConfig")

if __name__ == "__main__":
    app.run(debug=True)
```
