# Contributing to WyFlask

Thank you for your interest in contributing to WyFlask!

## Development Setup

1. Clone the repository
2. Create a virtual environment
3. Install dependencies: `pip install -e .[dev]`

## Testing

Run tests with `pytest`.
Please ensure tests pass before submitting pull requests.

## Code Style

We use `ruff` for linting and formatting. Run `ruff check .` before committing.
